## 1. Stage 1: Zero-Token Codebase Orientation via Graft

> **Skill Required**: `graft-architecture-intelligence`

### Rule: Never Explore Blindly
Do NOT use broad regex searches (`grep`) or read entire multi-thousand line files to locate classes, interfaces, or method implementations. Always consult the local AST wiring graph generated by **Graft**.

### Step-by-Step Agent Commands:
1. **Inspect Repository Clusters & Hotspots**:
   ```powershell
   .\scripts\graft-query.ps1 map
   ```
   - Returns directory clusters (subsystems), hub symbols (most-called functions), and coupling hotspots in under 0.1 seconds, saving ~95% tokens compared to raw file reads.
2. **Find Exact Symbol Location & Line Span**:
   ```powershell
   .\scripts\graft-query.ps1 find <symbol_name>
   ```
   - Example: `.\scripts\graft-query.ps1 find LeaseStaticProxyUseCase` returns exact file path and line span `L6-L38`.
3. **Trace Callers & Blast Radius Before Modifying**:
   ```powershell
   .\scripts\graft-query.ps1 callers <symbol_name>
   ```
   - Check all dependent callers before modifying function signatures or method behaviors.
4. **Targeted File Reads**:
   - Open only the specific line range identified in the Graft card (e.g. `read` with offset/limit) instead of reading the entire file.
5. **Rebuild AST Graph After Modifications**:
   ```powershell
   .\scripts\graft-build.ps1
   ```

## 2. Stage 2: Architecture Decomposition & Invariant Planning

> **Skills Required**: `architectural-decomposition` & `guarding-architecture`

Before writing or editing code:
1. **Identify the Target Subsystem**:
   - **Tier 1 (Go Core)**: `engine/` (Daemon, Checker, Failover, Surge Rotator, AdBlock, SQLite WAL) and `client/` (Wails GUI, `proxy-cli`, SOCKS5/HTTP relays).
   - **Tier 2 (Embedded Web)**: `engine/static/` (6-Tab glassmorphic dashboard on port `:9090`).
   - **Tier 3 (Cloud SaaS)**: `saas/` (Node.js 20+ / TypeScript Clean Hexagonal Architecture, Prisma ORM, Supabase, Redis).
2. **Enforce Core Invariants**:
   - `INV-01: Single Source of Core Logic`: Wails GUI and CLI share `client/internal/core` 100%.
   - `INV-02: Zero-Leak Surge Rotation`: In-flight TCP sessions finish on prior proxy; new handshakes use the new proxy.
   - `INV-03: Thread-Safe State Isolation`: All Go pool and adblock mutations protected by `sync.RWMutex`.
   - `INV-04: Clean Hexagonal Boundary in SaaS`: Domain layer (`saas/src/core/domain`) has 0 external dependencies.

## 3. Stage 3: Containerized Build & Environment Isolation

> **Skills Required**: `docker-containerization` & `docker-workspace-engineering`

### Rule: Hermetic Build Isolation
Do not rely on local host compilers or SDK versions. Use multi-stage Docker environments for compilation and testing.

### Step-by-Step Agent Commands:
1. **Build Go Engine Daemon in Docker**:
   ```bash
   docker build -t proxy-engine:prod -f ./engine/Dockerfile .
   ```
2. **Build Node.js SaaS Platform in Docker**:
   ```bash
   docker build -t proxy-saas-api:prod ./saas
   ```
3. **Run Isolated PostgreSQL & Redis via Docker Compose**:
   ```bash
   cd saas
   docker-compose up -d
   ```
4. **Run Supabase Stack via Docker Compose**:
   ```bash
   cd saas
   docker-compose -f docker-compose.supabase.yml up -d
   ```

## 4. Stage 4: Polyglot Implementation Standards

### A. Go 1.22+ Implementation Guidelines (`engine/`, `client/`, `shared/`)
- Multi-module workspace governed by root `go.work`.
- Statically linked builds (`CGO_ENABLED=0`) with stripped symbols (`-ldflags="-s -w"`).
- Standard library `log/slog` for structured logging.
- SQLite connections opened with WAL mode (`PRAGMA journal_mode=WAL;`) and busy timeouts (`PRAGMA busy_timeout=5000;`).

### B. Node.js 20+ & TypeScript Standards (`saas/`)
- **Domain Layer (`core/domain`)**: Pure immutable entities, value objects, domain exceptions.
- **Ports Layer (`core/ports`)**: Abstract interfaces (`IUserRepository`, `IProxyRepository`).
- **Use-Cases Layer (`core/use-cases`)**: Business logic implementations.
- **Infrastructure Layer (`infrastructure/`)**: Concrete Prisma PostgreSQL / Supabase repositories.
- **Presentation Layer (`presentation/`)**:
  - `request-id.middleware.ts`: Generates/propagates `X-Request-Id`.
  - `idempotency.middleware.ts`: Deduplicates mutations via `Idempotency-Key` in Redis.
  - `rfc7807-error.middleware.ts`: Formats errors as `application/problem+json`.

> **Skills Required**: `systematic-debugging` & `api-contract-audit`

Never consider a task complete without executing automated test verification.

### Step-by-Step Verification Commands:

## 6. Stage 6: Forensic Code Review & Security Audit

> **Skill Required**: `code-review`

Before finalizing changes, execute the Zero-Tolerance Security Scan:
1. **Command Injection**: Verify no `shell=True` or unparameterized subprocess calls exist.
2. **Path Traversal**: Ensure all file operations use `filepath.Join` or `resolve()` with root boundary checks.
3. **Secret Containment**: Confirm zero plaintext tokens, passwords, or high-entropy credentials exist in committed code or logs.
4. **Zero-Stub Discipline**: Guarantee 0 placeholder `pass`, `...`, or unhandled `# TODO` markers in active execution paths.
