# 🖥️ Wails Desktop GUI Subsystem (`client/frontend/`)

The Desktop GUI is a modern, dark-theme desktop application built with **Wails v2**, **React 18**, and **Tailwind CSS**.

---

## 1. Screens & Navigation

1. **Home Screen**: Main connect/disconnect toggle, active proxy display with country flag, live ping meter, and Surge mode indicators.
2. **Rotation Screen**: Surge rotation configuration with interval sliders, strategy selectors, and score filters.
3. **Devices Screen**: Local network client monitor displaying connected LAN devices.
4. **Settings Screen**: Local port assignments and authentication settings.
