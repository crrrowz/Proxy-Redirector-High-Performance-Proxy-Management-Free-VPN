# 💬 Getting Support for Proxy Redirector

Thank you for using **Proxy Redirector & Free VPN**. This guide explains where and how to get help, report bugs, ask questions, or request new features.

---

## 🧭 Support Channels

| Need | Channel | Details |
| :--- | :--- | :--- |
| **Bug Reports** | [GitHub Issues](https://github.com/crrrowz/Proxy_redirector/issues) | Report unexpected errors, panics, crashes, or regressions. |
| **Feature Requests** | [GitHub Discussions / Issues](https://github.com/crrrowz/Proxy_redirector/issues) | Propose new capabilities, protocol extensions, or integrations. |
| **Security Vulnerabilities** | **Private Disclosure** | Follow [SECURITY.md](SECURITY.md) to open a private advisory with [@crrrowz](https://github.com/crrrowz). **DO NOT** file public issues for security vulnerabilities. |
| **General Discussions** | [GitHub Discussions](https://github.com/crrrowz/Proxy_redirector/discussions) | Ask questions, discuss deployment strategies, and share feedback. |

---

## 🐛 Submitting a High-Quality Bug Report

Before opening a bug report:
1. **Search Existing Issues**: Check if the problem has already been reported or solved.
2. **Review Troubleshooting**: Check [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) for known diagnostic steps (e.g. port conflicts, proxy reachability).
3. **Include the Following Details**:
   - **Environment**: OS (Windows 10/11, Ubuntu 22.04/24.04, macOS), Go version, Node.js version.
   - **Subsystem**: Engine Daemon, Wails Desktop GUI, Headless CLI (`proxy-cli`), or SaaS API.
   - **Steps to Reproduce**: Clear, numbered step-by-step sequence.
   - **Logs & Error Output**: Sanitized logs (ensure you strip passwords, API keys, or private tokens).
   - **Expected vs. Actual Behavior**: What did you expect to happen, and what occurred instead?
